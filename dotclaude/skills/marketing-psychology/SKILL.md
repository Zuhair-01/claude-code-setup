# marketing-psychology

Full textbook: `Second_Brain/30-Resources/Curriculum/Product_Business_5_Pillars_Mastery.md` (§5A, §5C).
This skill is the working checklist. Companion: `social-growth-science` for reels/carousels/posts.

## When invoked, run this pass

### 1. Diagnose awareness stage (Schwartz) — sets everything
Unaware → Problem-aware → Solution-aware → Product-aware → Most-aware.
The hook must meet the reader where they are. Most-aware wants a deal; unaware needs a story/hook first.
Mismatch here is the #1 reason copy fails.

### 2. Nail the value equation (Hormozi) — audit the offer
```
Value = (Dream Outcome × Perceived Likelihood) / (Time Delay × Effort)
```
Push each lever: bigger true outcome · more proof/guarantee · faster first result · less work for them.
Test: "would the target feel stupid saying no?"

### 3. Answer the 5 objections before they're spoken
time · money · "won't work for me" · trust · "not now". Each needs a specific counter in the copy.

### 4. Apply persuasion principles (Cialdini +1) — pick the 2–3 that fit, don't spray
reciprocity · commitment/consistency · social proof (specific numbers + named) · authority · liking (founder visible) · scarcity (REAL only) · unity (in-group frame).

### 5. Apply behavioral levers where relevant
- **Loss aversion** — frame the cost of *not* acting, not just the gain.
- **Anchoring** — show the high number / total value first.
- **Framing** — "$1/day" not "$30/mo"; "90% keep it" not "10% churn".
- **Decoy** — a deliberately worse option makes the target plan obvious.
- **Hyperbolic discounting** — emphasize speed to first result.
- **Cognitive load** — one primary CTA per page; delete options, fields, words.
- **Zeigarnik** — progress bars, open loops.
- **Peak-end** — design the aha moment + the receipt/offboarding.

### 6. Structure the copy (pick by length)
PAS (short, problem-aware) · AIDA (versatile) · BAB (transformation) · 4Ps (ads/LP) · PASTOR (long sales page) · FAB (translate every feature→benefit).
Headline: 4 U's — Useful, Urgent, Unique, Ultra-specific. Ogilvy: headline is 80% of the work; cut adjectives, add a specific number/fact.

### 7. Map benefit to a primal driver (LIFEFORCE 8)
survival/health · food/drink · freedom from fear/pain · companionship · comfort · status/winning · protecting loved ones · social approval.

## Output format
1. Awareness stage + the mismatch you found.
2. Offer audit against the value equation (4 levers, what's weak).
3. Rewritten hook (3 variants).
4. Rewritten body using the chosen framework.
5. The 2–3 persuasion principles applied and where.
6. One CTA, with the reason-to-act-now.

## Hard rules
- Never fake scarcity/urgency/social proof. It converts once and destroys trust + deliverability forever.
- Specificity beats adjectives. "3,412 founders" not "thousands of happy customers".
- Emotion sells, logic justifies — give them both, in that order.
- If the positioning is unclear, stop and fix that first (route to `taste-skill`/curriculum §5B Dunford). Copy can't rescue bad positioning.
