## Installation

### Bundle-by-Bundle
Each bundle is a git submodule or npm package reference:

```bash
# Activate Clipping Factory bundle
skill-install bundle-clipping-factory

# Activate AI-UGC bundle
skill-install bundle-ai-ugc

# Etc.
```

### All Bundles at Once
```bash
skill-install bundle-empire-base-all
```
