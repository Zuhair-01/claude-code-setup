thebrand.md defines BRAND.md: one markdown file, YAML frontmatter
(`name`, `tagline`, `specVersion`, `version`, `language`), four layers —
Strategy (overview, audience, positioning, personality, references,
promise, guardrails), Voice (identity, taglines/slogans, message pillars,
phrases, vocabulary, tonal rules), Visual (logo/marks, core colors,
typefaces, imagery, art direction), Governance/optional (naming, claims,
accessibility). Rule of thumb from the standard itself: "if it should
survive a complete visual redesign, it belongs in BRAND.md; if it could
change during that redesign without repositioning the company, it belongs
in DESIGN.md."

Used as the schema for `brand.md` files in [[project_growth_os_registry]]
(trimmed to fields with actual evidence, rest marked UNKNOWN).
