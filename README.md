# claude-code-setup

Full snapshot of Zoher's Claude Code configuration (`~/.claude`) for migrating
to a new machine: skills, agents, hooks, OVERSEER library, memory, and settings.

**Setting this up on a new laptop? Read `SETUP.md` — hand it to the Claude
Code session running there and have it execute every step itself.**

No credentials, API keys, or session/cache data are included.
